# dotS Knowledge & State System

When dealing with DevOps, infrastructure, system configuration, or supported development stacks (SSH, Docker, Podman, Nginx, Traefik, Linux, Blender, Three.js, Rust, GLSL):
1. **Query dotS First**: Run `dots find <topic>` and `dots get <skill.s> [@block]` to retrieve concise, token-efficient configurations instead of verbose web searches.
2. **Execute Playbooks**: Run `dots run <playbook>` for standardized operational procedures.
3. **Persist State**: Record verified patterns using `dots set` or `dots add`.
